# Guides

  Update a pack and what you added, and keep your changes.

- ![](../assets/pixel/key.svg) [Use CurseForge](curseforge.md)

  Set up a key, and install files you must download by hand.

- ![](../assets/pixel/link.svg) [Take over an existing installation](existing.md)

  Manage an installation you made in the launcher yourself.

- ![](../assets/pixel/wrench.svg) [Manage instances](instances.md)

  Start empty instances, rename, move and delete them.
